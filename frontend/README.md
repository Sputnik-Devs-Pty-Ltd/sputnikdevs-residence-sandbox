# Track 02 Workspace: Frontend & Modern Web UI (`frontend/`)

Welcome to the **Track 02 (Frontend & Modern Web UI Engineering)** workspace for the Sputnik Devs Residence Sandbox.

## Getting Started
1. Start the Backend Sandbox API in Terminal 1:
   ```bash
   dotnet run --project ../SputnikDevs.Residence.SandboxApi
   ```
2. Serve or open your frontend application in `frontend/` and connect to `http://localhost:5035/api/v1/rooms`, `/api/v1/students`, `/api/v1/tickets`, and `/api/v1/dashboard/summary`.
3. Follow your 19-Day syllabus in **[../docs/tracks/TRACK_02_FRONTEND_UI.md](../docs/tracks/TRACK_02_FRONTEND_UI.md)** and log your daily Pull Requests on **[https://sputnikdevs.com/academy/portal](https://sputnikdevs.com/academy/portal)**.
