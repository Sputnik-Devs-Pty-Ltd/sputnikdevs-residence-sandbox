# Track 02B: Blazor / Razor & Modern Web UI (`frontend/web-blazor-razor/`)

Welcome to **Track 02B (`SD-FE-101..104`) — Blazor / Razor & Modern Web UI** inside the **Sputnik Devs Residence Sandbox** monorepo.

## Quick Start
1. Start the `.NET 10` Sandbox API in Terminal 1:
   ```bash
   dotnet run --project ../../SputnikDevs.Residence.SandboxApi
   ```
2. Build your responsive Residence Operations UI (`index.html`, `apiClient.js`, or Blazor WebAssembly components) inside `frontend/web-blazor-razor/` connecting to `http://localhost:5035/api/v1/rooms`, `/api/v1/students`, and `/api/v1/tickets`.
3. Follow the 19-Day milestone schedule in **[`../../docs/tracks/TRACK_02_FRONTEND_UI.md`](../../docs/tracks/TRACK_02_FRONTEND_UI.md)**.
