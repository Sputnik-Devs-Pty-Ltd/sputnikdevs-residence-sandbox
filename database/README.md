# Track 03 Workspace: Database Administration & Data Engineering (`database/`)

Welcome to the **Track 03 (Database Administration, SQL & Data Engineering)** workspace for the Sputnik Devs Residence Sandbox.

## Getting Started
1. Start PostgreSQL 16 in Codespaces or local Docker:
   ```bash
   ../scripts/start-postgres.sh
   ```
2. Place your daily SQL scripts, DDL constraints, composite index migrations, views, stored functions, and `EXPLAIN ANALYZE` benchmark reports inside this `database/` directory.
3. Follow your 19-Day syllabus in **[../docs/tracks/TRACK_03_DATABASE_SQL.md](../docs/tracks/TRACK_03_DATABASE_SQL.md)** and log your daily Pull Requests on **[https://sputnikdevs.com/academy/portal](https://sputnikdevs.com/academy/portal)**.
