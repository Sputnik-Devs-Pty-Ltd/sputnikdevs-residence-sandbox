# Track 02 Workspace: Modern Web & SaaS UI (`frontend/`)

Welcome to the **Track 02 (`SD-FE-101..104`: Modern Web & SaaS UI Engineering)** workspace inside the unified **Sputnik Devs Residence Sandbox** polyglot monorepo.

Students enrolled in Track 02 choose one of two industry frontend sub-tracks while consuming the exact same **.NET 10 Residence Sandbox API** (`http://localhost:5035/api/v1/...`):

| Sub-Track | Folder | Tech Stack |
| :--- | :--- | :--- |
| **Track 02A: Angular Enterprise SPA** | [`frontend/web-angular/`](web-angular/README.md) | **Angular 19+**, TypeScript 5, Standalone Components, Angular Signals, RxJS, Reactive Forms, Tailwind CSS |
| **Track 02B: Blazor / Razor & Modern Web UI** | [`frontend/web-blazor-razor/`](web-blazor-razor/README.md) | **HTML5 / Razor / Blazor**, Tailwind CSS, ES6+ Fetch Client (`apiClient.js`), Responsive Dashboard Components |

---

## Quick Start (Both Sub-Tracks)

1. **Start the Backend Sandbox API in Terminal 1:**
   ```bash
   dotnet run --project ../SputnikDevs.Residence.SandboxApi
   ```
   The API boots on `http://localhost:5035` (Swagger UI at `http://localhost:5035/swagger`).

2. **Open your chosen Frontend Sub-Track in Terminal 2:**
   * **For Angular (`Track 02A`):** See [`frontend/web-angular/README.md`](web-angular/README.md)
   * **For Blazor / Modern Web (`Track 02B`):** See [`frontend/web-blazor-razor/README.md`](web-blazor-razor/README.md)

3. Follow your 19-Day syllabus in **[`../docs/tracks/TRACK_02_FRONTEND_UI.md`](../docs/tracks/TRACK_02_FRONTEND_UI.md)** and submit your daily Pull Requests on **[https://sputnikdevs.com/academy/portal](https://sputnikdevs.com/academy/portal)**.
